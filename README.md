# OnlyOfficeTestTask

Мобильное приложение выполенно в рамках тестового задания. 
---
- Экран авторизации на портале с валидацией ввода полей адреса портала и email
- Экран со списком документов(папки и файлы), папки можно открыть и провалиться на следующий экран содержимого папки
- Экраны созданных комнат и удаленых файлов
- Экран профиля с возможностью разлогиниться
